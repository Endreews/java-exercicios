# Exercícios Iniciais em Java

Este repositório contém exercícios simples desenvolvidos durante meu processo de reaprendizado da linguagem Java.

Bootcamp Santander 2026 - AI Java Back-end

Aula - Fundamentos da Linguagem de Programação Java

Acerto: 70%

O objetivo deste projeto é praticar conceitos básicos da linguagem, como entrada de dados, variáveis, operadores aritméticos, uso da classe `Scanner` e exibição de resultados no console.

## Exercícios desenvolvidos

### 1. Cálculo de idade

Programa que recebe o nome e o ano de nascimento de uma pessoa e exibe uma mensagem informando sua idade aproximada.

Arquivo: `Ano.java`

### 2. Área de um quadrado

Programa que recebe o tamanho do lado de um quadrado, calcula sua área e exibe o resultado.

Fórmula utilizada:

```java
area = lado * lado;
```

Arquivo: `AreaQuadrado.java`

### 3. Área de um retângulo

Programa que recebe a base e a altura de um retângulo, calcula sua área e exibe o resultado.

Fórmula utilizada:

```java
area = base * altura;
```

Arquivo: `AreaRetangulo.java`

### 4. Diferença de idade

Programa que recebe o nome e a idade de duas pessoas e exibe a diferença de idade entre elas.

Arquivo: `DifIdade.java`

## Conceitos praticados

* Criação de classes em Java
* Método `main`
* Entrada de dados com `Scanner`
* Variáveis do tipo `int` e `String`
* Operadores aritméticos
* Impressão de dados no console com `System.out.println` e `System.out.printf`
* Organização de arquivos Java

## Como executar

Para executar qualquer exercício, abra o projeto em uma IDE como IntelliJ IDEA ou VS Code e rode o arquivo desejado.

Também é possível executar pelo terminal:

```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```

Exemplo:

```bash
javac Ano.java
java Ano
```
